# 简易人脸识别
　　五一闲来无事，家教时学生说想知道人脸识别的原理，便整了一个如此项目，以做娱乐，正好直观感受一下卷积神经网络的优势与局限，并进一步了解了其他相关的人脸识别算法与经验，感触颇多。  
　　第一个“简单CNN”即是用传统的卷积结构+线性隐藏层结构，最后一层输出的是对应四个人的概率，损失函数是经典的交叉熵损失函数。  
　　由于四个人的面部照片我只各找了不到十张，导致传统的卷积神经网络极易过拟合，虽然训练集已达到100%的准确率，但测试集的准确率只有60-70%左右，而且仅局限于比较相近的照片，一旦面部占比变小，或者增加一些表情、带个墨镜之类的，就很难正确识别了。  
　　因此，为了解决小样本训练的局限，第二个（“改进版CNN”）是用GPT给我的方案。这个相对第一个方案巧的地方在于隐藏层输出的并不是四个类别的概率，而是输出一个给定维数的向量（如代码中的128维），每一个维度相当于一个特征。因此这种方法实际上是把每个人都训成一个独特向量，再给定一个新的测试案例时，提取出该新案例的特征以后，计算与各个已知类别的欧式距离，选取距离最近的即是该新案例的类别。  
　　虽然两种方法均无法很好地解决低样本带来的局限性，但我发现一个很有意思的地方，他们竟然都可以识别出如下表情包所对应的主人，而且准确率与本人极高！要知道这可是ｍｙ八年前的照片，而且还加了小丑鼻子（xswl）
